## A still screen keeps its sound

In 0.9.119, turning **System audio** on with a microphone and recording a
screen that barely changed could save a valid file whose audio track was
silent. The picture looked fine; every sample was zero.

This Beta keeps microphone and System audio lined up with the picture when
the screen is still, paused, or slow to change. A moving screen and a camera
layout behave as before.

If audio cannot be placed for a moment, the mixer says so in plain words
instead of claiming the microphone stopped. The session keeps going.

## System audio stays as shipped

The System audio switch from 0.9.119 is unchanged: On or Off in Studio, live
meter, mid-session toggle, global shortcut, phone remote and Stream Deck.
Default stays **Off**. Screen Recording permission is still required for
System audio.
