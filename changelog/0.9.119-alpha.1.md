This is the next Windows and Linux Alpha after 0.9.118-alpha.1. On Windows you
can finally capture what the PC is playing. On Linux, System audio is not in
this cut yet; the build still carries the 0.9.118 microphone, camera and
screen-preview work.

## System audio on Windows

Turn **System audio** **On** in the Studio mixer or Studio inputs and
recordings and every stream leg include what Windows is playing: browser tabs,
games, music, calls. Turn it **Off** and only your microphone and the sources
you chose stay in the mix. The default is **Off**.

You can flip it mid-session. The mixer shows a live meter while it is on.
Sources → Audio mixer adds a gain slider (default −6 dB). Bind **Turn system
audio on/off** in Settings → Global shortcuts, use the phone remote, or a
Stream Deck action.

Windows captures through WASAPI process loopback and excludes Videorc's own
process tree, so the app's UI sounds do not feed back into the recording. If
capture cannot start (for example when the microphone is on a fallback input),
the row says so and the session keeps going without system audio.

## Linux

Linux Alpha still has no System audio switch in this cut. Keep using the
0.9.118 PipeWire/Pulse microphone, V4L2 camera and portal screen-preview
fixes. Treat the AppImage as a test artifact, not a supported production
install.

Windows remains an Alpha. See the [Windows Alpha notes](https://www.videorc.com/windows-alpha)
for supported hardware and current limitations.
