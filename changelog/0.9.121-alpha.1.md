This is the next Windows and Linux Alpha after 0.9.118-alpha.1. The earlier
0.9.119 and 0.9.120 Alpha candidates did not ship; this cut replaces them.

## System audio on Windows

Turn **System audio** **On** in the Studio mixer or Studio inputs and
recordings and every stream leg include what Windows is playing. Turn it
**Off** and only your microphone and the sources you chose stay in the mix.
The default is **Off**.

You can flip it mid-session. The mixer shows a live meter. Sources → Audio
mixer adds a gain slider (default −6 dB). Bind **Turn system audio on/off**
in Settings → Global shortcuts, use the phone remote, or a Stream Deck
action.

Windows captures through WASAPI process loopback and excludes Videorc's own
process tree. If capture cannot start, the row says so and the session keeps
going without system audio.

A still or barely changing screen no longer writes a silent microphone or
System audio track when those inputs are on.

## On both Windows and Linux

- **Highlighted comments on vertical streams.** With a vertical destination
  armed beside a horizontal one, a highlighted comment used to show as
  **On stream** but appear on neither video. It now shows on both, with a
  card sized for the vertical frame.
- **New followers, by name.** Activity shows who followed you, with their
  avatar, and **Thank in chat** mentions their handle. On Twitch, click
  **Show who followed** once to allow it. On X, followers are named when X
  delivers them; otherwise X shows a count as before.
- **Glass menus and popovers.** Hover cards, menus, tooltips, dialogs and
  toasts match the window instead of near-black panels.
- **Refresh while live.** Refreshing during a session no longer shows an
  account warning, and a newly connected camera shows up.

## Linux

Performance check now measures encoding honestly on synthetic noise, so a
capable machine is not failed by skipped frames. Real recording sessions are
unchanged.

On Wayland (for example Hyprland), the docked Studio preview stays in its
slot instead of appearing centred over the app. Floating preview windows
still follow the preview window.

Linux Alpha still has no System audio switch in this cut. Keep using the
PipeWire/Pulse microphone, V4L2 camera and portal screen-preview work from
0.9.118. Treat the AppImage as a test artifact, not a supported production
install.

Windows remains an Alpha. See the [Windows Alpha notes](https://www.videorc.com/windows-alpha)
for supported hardware and current limitations.
